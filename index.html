VEX PROTOCOL SPECIFICATION • VERSION 2.0

VEX Typed JSON-RPC 2.0 & Register Wire Standard

The VEX RPC protocol defines a deterministic, high-throughput RPC standard for verifiable state updates, decentralized registers, and reactive UI subscriptions.

1. JSON-RPC 2.0 Envelope Format

All VEX requests are strict JSON-RPC 2.0 payloads sent via HTTP POST with `Content-Type: application/json` and signed with an Ed25519 header. 

// Standard Request
{
  "jsonrpc": "2.0",
  "id": "req-unique-uuid-v4",
  "method": "vex_commitState",
  "params": {
    "register": "#01",
    "account": "0x71a2...98c1",
    "delta": 125.50,
    "nonce": 104
  }
}

2. Register Addressing Architecture (`#01`, `#02`, `#03`, `#04`)

#01 @state — Core Mutation Register

Stores global verifiable state root, account nonces, token balances, and consensus variables. Requires SHA-256 pre-image and Ed25519 signature.

#02 @rpc — Execution Channel

Executes synchronous and async smart functions, gas/credit deductions, and external cross-chain or zero-knowledge proof checks.

#03 @ui — Reactive View Register

Dispatches UI tree render manifests, terminal layouts, and WebSub push updates directly to connected frontend clients.

#04 @bus — Event Stream Register

High-throughput WebSocket event publishing for block confirmations, mempool entries, and node peer heartbeats.

3. Verification Lifecycle (5-Stage Pipeline)

STAGE 1
Deterministic Content Digest: Canonical JSON stringification followed by SHA-256 hash generation.
STAGE 2
Ed25519 Cryptographic Check: Node checks request signature header against registered public key.
STAGE 3
Register Lock & Nonce Verification: Prevents replay attacks by checking account sequence.
STAGE 4
State Transition Execution: Applies state delta to register `#01` and returns execution status.
STAGE 5
Block Attestation & Revert Anchor: Generates block hash for atomic point-in-time state recovery.

4. Error Codes & Diagnostics

Code Message Meaning & Recovery
-32700 Parse error Malformed JSON input in RPC request body.
-32600 Invalid Request Missing jsonrpc "2.0" field or invalid identifier.
-32001 VEX_REGISTER_CONFLICT Concurrent lock conflict on register address `#01`.
-32002 VEX_INVALID_SIGNATURE Ed25519 signature digest mismatch or unauthorized key.
